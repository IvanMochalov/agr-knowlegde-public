# Подача заявления в Архитектурную комиссию

Практическая инструкция по ЛК СтроимПросто. Детали полей и скриншоты шагов — в `raw/stroimprosto-arh.md` и в [обновлённой статье портала](https://stroimprosto.mos.ru/knowledge/article/arh). Этапы и состав — [этапы-согласования](этапы-согласования.md), [требования-к-материалам](../concepts/требования-к-материалам.md).

## Подготовка

1. ЭЦП организации / уполномоченного лица (инструкция портала: статья про ЭЦП в ЛК).
2. Статус **«застройщик»** в ЛК СтроимПросто: вход под учётной записью **mos.ru юридического лица** и запрос на роль «Застройщик» (иначе форму заявки не собрать).
3. Выбор [этапа](этапы-согласования.md): концепция / НПМ / ВПМ / иное — с учётом [маршрута бюджет/коммерция](этапы-согласования.md#маршруты).
4. Услуга: **«Заявление в Архитектурную комиссию ДГП»** → отслеживание в разделе заявок ЛК.

## Два сценария формы

### Вариант A. Мэр уже одобрил ВПМ и ЦИМ, свидетельства ещё нет

Поле «Проект согласован Мэром Москвы» = **Да**. Дальше — реквизиты письма ДГП (МКА) об одобрении, загрузка уже согласованных моделей (ВПМ, НПМ, ссылка на проверку IFC). После 30.09.2026 для новых дел этот сценарий реже нужен: свидетельство уходит проактивно. Имеет смысл для «хвостов» переходного периода. В этом сценарии подача по доверенности **не предусмотрена**.

### Вариант B. Первичная подача / корректировка / изменение свидетельства

«Проект согласован Мэром» = **Нет**. Затем вид материалов (концепция, НПМ, ВПМ…).

**Роль организации:**

- **Заинтересованное лицо** — застройщик, на него оформляется свидетельство.
- **Представитель заинтересованного лица** — по доверенности / договору.

**Тип обращения:**

- Обращение впервые;
- Корректировка материалов, по которым ранее получены замечания;
- Корректировка ранее одобренных материалов в целях внесения изменений в свидетельство АГР.

Повторная подача после замечаний — **всегда новое заявление** с типом корректировки, не правка старой карточки. См. [замечания-и-корректировка](замечания-и-корректировка.md).

## Сведения о проекте (важное для менеджера)

- **Источник ТЭП:** ГЗК / ГПЗУ / ППТ и т.п. Если есть и РГ ГЗК, и ГЗК — указывают **ГЗК** (с пунктом протокола).
- **УИН / адрес:** объекты, где организация — застройщик в цифровом паспорте. Нет в списке → «Проект не найден» + ручной ввод или `grad@mos.ru`.
- **GEOJSON МСК-77** — контур территории в метрических координатах (не градусы); при нескольких объектах — отдельный контур на каждый.
- Кадастровый / условный номер ЗУ, площадь, ВРИ, параметры объекта, машино-места, плановый срок.

## Загрузка на этапе ВПМ (типовой наш кейс)

Обязательно (по статье):

- ВПМ ZIP + `.sig` (имя подписи = имя ZIP);
- НПМ ZIP + `.sig`;
- URL результата проверки чекером IFC (`cimcheck` в ЛК);
- буклет / презентация / транспорт / GEOJSON — по перечню системы для вида материалов;
- СПОЗУ (DWG) — для инвестиционных нелинейных или несоциальных объектов.

Опционально: иные PDF, до 5 файлов, до 100 МБ каждый.

Буклет, презентация, транспорт и прочее система запрашивает по виду материалов — их готовит заказчик/проектировщик. См. [исходные-данные](../concepts/исходные-данные.md), [роль-команды](../team/роль-команды.md).

## Подпись архивов

У каждого ZIP — файл подписи УКЭП с тем же именем. Подписать может руководитель, ИП, уполномоченное лицо или организация, подготовившая модели. Подпись должна быть действительна **на момент подписания**.

В сертификате для руководителя / уполномоченного лица статьи ожидают ФИО, должность, организацию, дату подписания и срок действия сертификата; для ИП — ФИО, ОГРНИП, дату подписания и срок действия. Чью ЭП ставим на договоре — фиксируем отдельно.

## Частые сбои портала (из FAQ статьи)

- **Не формируется заявка** — проверить вход от юрлица mos.ru и роль «Застройщик».
- **Несколько юрлиц в одном профиле** — «Профиль» → «Добавить компанию»; заявки фильтруются по выбранной организации.
- **ЭЦП не подписывает** — пройти инструкцию ЭЦП ЛК на портале.
- **Нет УИН в списке** при верном застройщике — в СТП `grad@mos.ru` (ответ до 1 р.д.).
- **Повтор после отказа/замечаний** — тип обращения «Корректировка материалов, по которым ранее получены замечания».
