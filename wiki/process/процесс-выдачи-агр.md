# Процесс выдачи свидетельства АГР в Москве

Сквозная карта для менеджера. Детали этапов — в [этапы-согласования](этапы-согласования.md), подача — в [подача-заявления](подача-заявления.md), документ — в [свидетельство-агр](свидетельство-агр.md), наша зона — в [роль-команды](../team/роль-команды.md).

## Зачем АГР

[Архитектурно-градостроительное решение](../concepts/АГР.md) фиксирует, как объект встраивается в город: облик, высотность и этажность, планировочная структура, материалы фасадов и благоустройства. Утверждённое решение ([свидетельство-агр](свидетельство-агр.md)) нужно до экспертизы проектной документации и служит основанием для дальнейшего движения к разрешению на строительство.

Согласование нужно при строительстве и реконструкции ОКС (кроме реконструкции без изменения внешнего облика). Не требуется для ОКС и объектов культурного наследия / выявленных ОКН.

## Картина после 30.09.2026

Раньше: Архкомиссия → совещание с Мэром → отдельная госуслуга «оформить свидетельство» на mos.ru.

Сейчас:

1. Застройщик готовит проектные материалы, включая [комплект-моделей](../concepts/комплект-моделей.md).
2. Подаёт заявление в [Архитектурную комиссию](архкомиссия.md) через личный кабинет СтроимПросто (услуга «Заявление в Архитектурную комиссию ДГП»).
3. Комиссия рассматривает материалы (регламент — до [20 рабочих дней](сроки-и-статусы.md)).
4. При направлении на Мэра — совещание; при одобрении и если ПЗЗ менять не нужно, [ДГП](../concepts/ДГП.md) **сам** направляет свидетельство в личный кабинет (обычно в течение 2 рабочих дней после протокола).
5. Если нужны изменения ПЗЗ — ждут акт Правительства Москвы, после него свидетельство тоже уходит проактивно.

Отдельную госуслугу «оформить свидетельство» больше не заказывают. Подробнее — [свидетельство-агр](свидетельство-агр.md).

## Типовой путь коммерческого застройщика

```text
Исходные данные (буклет, ТЭП, RVT/DWG, СПОЗУ)
        ↓
Изготовление моделей: НПМ + ВПМ + ЦИМ (IFC + XML ТЭП)
        ↓
Сборка комплекта + подписи ZIP + GEOJSON МСК-77 + ссылка на проверку ЦИМ
        ↓
Заявление: этап «Согласование ВПМ»
        ↓
Приём / отказ в приёме (до 2 р.д.) → рассмотрение комиссии (до 20 р.д.)
        ↓
Одобрение / замечания / направление на Мэра
        ↓
(при замечаниях) корректировка → новое заявление типа «корректировка…»
        ↓
Одобрение на совещании с Мэром
        ↓
Свидетельство в ЛК (если ПЗЗ ок) или ожидание акта по ПЗЗ
```

Для коммерции именно этап **ВПМ** — тот, на котором статья СтроимПросто связывает итог со свидетельством. Этап «Согласование НПМ» даёт одобрение Мэра на НПМ и ЦИМ, но для обычного коммерческого объекта свидетельства ещё нет — нужна детализация через ВПМ. Исключения — [исключения](исключения.md).

Предварительная концепция с НПМ ([этапы-согласования](этапы-согласования.md)) — ранний шаг без свидетельства и без обязательного IFC.

## Где в процессе мы

| Шаг | Кто | Комментарий |
| --- | --- | --- |
| Буклет, презентация, транспорт, право на участок | Заказчик + проектировщики | В цену моделей не входит |
| НПМ / ВПМ / ЦИМ | Команда | Ядро КП |
| Проверка по чек-листу, доработка по замечаниям к моделям | Команда | В цене этапа |
| Заявление в СтроимПросто, статус, повторная подача | Заказчик **или** мы при сопровождении ([роль-команды](../team/роль-команды.md)) | Сопровождение — отдельная строка |
| Решение комиссии / Мэра / свидетельство | Город (ДГП) | Дату выдачи не обещаем |
