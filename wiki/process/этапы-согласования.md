# Этапы согласования на Архитектурной комиссии

От выбранного этапа зависят состав файлов и то, появится ли [свидетельство-агр](свидетельство-агр.md). Опора — статья СтроимПросто «Заявка на Архитектурную комиссию» и Порядок из 1423-ПП.

Для типового коммерческого объекта путь к свидетельству — **п. 3 (ВПМ)**. Наше КП с тремя моделями закрывает именно его. См. [комплект-моделей](../concepts/комплект-моделей.md), [роль-команды](../team/роль-команды.md).

---

## 1. Согласование концепции развития территории с НПМ

**Цель.** Предварительное одобрение Мэра: стилистика и базовые решения по территории.

**Кому.** Коммерческим и бюджетным застройщикам.

**Свидетельство.** Не выдаётся.

**Варианты подачи:**

- ≥ 3 варианта концепции + НПМ только по приоритетному;
- 2 варианта концепции + НПМ по каждому.

**Модели.** НПМ обязательна. **ЦИМ / IFC не требуется.**

**Из обязательного (по статье):** GEOJSON контура в МСК-77, буклет PDF, презентация PPTX, ZIP НПМ + `.sig`, раздел транспортного обслуживания PDF.

**Итог.** Предварительное одобрение концепции → дальше детализация к свидетельству.

---

## 2. Согласование НПМ

**Цель.** Более детальное рассмотрение ОКС: НПМ + ЦИМ (IFC).

**Кому.** Коммерческим и бюджетным.

**Свидетельство.**

- Обычный коммерческий застройщик: **ещё нет**. Итог — одобрение Мэра на НПМ и ЦИМ; дальше нужен этап ВПМ.
- Короткий список может закрыть свидетельство уже здесь: линейные объекты ДСТиИИ, Фонд реновации, АНО «Развитие социальной инфраструктуры», религиозные, отдельные промышленно-производственные, объекты за счёт бюджета города — см. [исключения](исключения.md).

**Особенности.**

- Несколько отдельно стоящих строений → ТЭП по каждому; сумма считается автоматически.
- На этапе ВПМ архив НПМ всё равно остаётся обязательным.

---

## 3. Согласование ВПМ {#впм}

**Цель.** Детализированный этап, ориентированный на коммерческих инвесторов / застройщиков.

**Кому.** В первую очередь коммерческим застройщикам.

**Свидетельство.** Да — при успешном прохождении (одобрение → Мэр → проактивная выдача, если ПЗЗ не требует правок).

**Модели.** **ВПМ + НПМ + ЦИМ (IFC)** вместе. Ссылка на результат проверки ЦИМ в ЛК обязательна в сценарии подачи.

Это тот городской этап, под который собрано стандартное КП: три строки НПМ / ВПМ / ЦИМ.

---

## 4. Концепция благоустройства территории

Отдельный вид материалов: согласование проекта благоустройства с НПМ. В стандартную цену моделей ОКС не входит — отдельный объём.

---

## 5. Прочие виды материалов

Выбираются в заявлении по необходимости (в ту же услугу комиссии, но не «комплект АГР ОКС»):

- арт-объекты, инсталляции, монументально-декоративное искусство;
- некапитальные объекты (архитектурно-художественное решение);
- архитектурно-художественные концепции для вывесок;
- крышные информационные / рекламные конструкции;
- реклама на фасаде;
- ветро-пылезащитные и защитные конструкции;
- архитектурно-художественное освещение.

В цену НПМ/ВПМ/ЦИМ по умолчанию не входят — см. [вопросы-заказчика](../team/вопросы-заказчика.md).

---

## Как не перепутать этапы в разговоре

| Заказчик говорит | Обычно имеется в виду |
| --- | --- |
| «Нам только концепцию» | Этап 1, одна НПМ, без IFC, без свидетельства |
| «Согласуем НПМ» | Этап 2: НПМ + ЦИМ; для коммерции свидетельство ещё не цель |
| «Идём на АГР / на свидетельство» | Этап 3: НПМ + ВПМ + ЦИМ |
| «Уберите НПМ, оставьте ВПМ» | На этапе ВПМ НПМ всё равно нужна |
