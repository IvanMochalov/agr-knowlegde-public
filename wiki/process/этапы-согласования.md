# Этапы согласования на Архитектурной комиссии

От выбранного этапа зависят состав файлов и то, появится ли [свидетельство-агр](свидетельство-агр.md). Опора — обновлённая статья СтроимПросто «Заявка на Архитектурную комиссию» и Порядок из 1423-ПП.

Для типового коммерческого объекта путь к свидетельству — **п. 3 (ВПМ)**. Стандартный комплект из трёх моделей закрывает именно его. См. [комплект-моделей](../concepts/комплект-моделей.md), [роль-команды](../team/роль-команды.md).

---

## Рекомендуемые маршруты (бюджет / коммерция) {#маршруты}

В обновлённой инструкции СтроимПросто отдельно показаны рекомендуемые шаги. Это **городские этапы подачи**, не состав файлов внутри этапа:

| Кто | Рекомендуемый путь к САГР |
| --- | --- |
| **Коммерческие застройщики** | 1) концепция с вариантами (этап 1) → 2) **ВПМ + IFC** (этап 3) → САГР |
| **Фонд реновации** | 1) концепция с вариантами → 2) **НПМ + IFC** (этап 2) → САГР |
| **ДСТиИИ** (линейные / дорожно-мостовые) | 1) концепция **без IFC** → 2) **НПМ + IFC** → САГР |
| **АНО РСИ**, религиозные, отдельные промышленно-производственные, объекты за счёт **бюджета города** | сразу **НПМ + IFC** (этап 2) → САГР |

Важно для коммерции: на этапе ВПМ город всё равно ждёт **ВПМ + НПМ + ЦИМ**. Маршрут «концепция → ВПМ» значит, что отдельный этап «Согласование НПМ» как путь к свидетельству коммерции не нужен — не то, что архив НПМ можно не готовить. Подробнее — [исключения](исключения.md).

## 1. Согласование концепции развития территории с НПМ

**Цель.** Предварительное одобрение Мэра: стилистика и базовые решения по территории.

**Кому.** Коммерческим и бюджетным застройщикам.

**Свидетельство.** Не выдаётся.

**Варианты подачи:**

- ≥ 3 варианта концепции + НПМ только по приоритетному;
- 2 варианта концепции + НПМ по каждому.

**Модели.** НПМ обязательна. **ЦИМ / IFC не требуется.**

**Обязательно (по статье):** GEOJSON контура в МСК-77, буклет PDF, презентация PPTX, ZIP НПМ + `.sig`, раздел транспортного обслуживания PDF.

**Необязательно:** фрагмент эскиза застройки ППТ (PDF), ситуационный план с эскизом (PDF).

**Итог.** Предварительное одобрение концепции → дальше детализация к свидетельству.

---

## 2. Согласование НПМ

**Цель.** Более детальное рассмотрение ОКС: НПМ + ЦИМ (IFC).

**Кому.** Коммерческим и бюджетным.

**Свидетельство.**

- Обычный коммерческий застройщик: **ещё нет**. Итог — одобрение Мэра на НПМ и ЦИМ; дальше нужен этап ВПМ.
- Короткий список может закрыть свидетельство уже здесь: линейные объекты ДСТиИИ, Фонд реновации, АНО «Развитие социальной инфраструктуры», религиозные, отдельные промышленно-производственные, объекты за счёт бюджета города — см. [исключения](исключения.md).

**Особенности.**

- Несколько отдельно стоящих строений → ТЭП по каждому; сумма считается автоматически.
- На этапе ВПМ архив НПМ всё равно остаётся обязательным.

**Из обязательного состава статьи:** GEOJSON на каждый объект, буклет, презентация, НПМ ZIP + `.sig`, транспорт PDF; **СПОЗУ (DWG)** — для инвестиционных нелинейных или несоциальных объектов.

**Итог.** Для коммерции — одобрение НПМ+ЦИМ и переход к ВПМ. Для списка исключений — САГР или замечания в ЛК.

---

## 3. Согласование ВПМ {#впм}

**Цель.** Детализированный этап, ориентированный на коммерческих инвесторов / застройщиков.

**Кому.** В первую очередь коммерческим застройщикам.

**Свидетельство.** Да — при успешном прохождении (одобрение → Мэр → проактивная выдача, если ПЗЗ не требует правок).

**Модели.** **ВПМ + НПМ + ЦИМ (IFC)** вместе. Ссылка на результат проверки ЦИМ в ЛК обязательна.

**Из обязательного состава статьи:** GEOJSON на каждый объект, буклет, презентация, URL проверки IFC, ВПМ ZIP + `.sig`, НПМ ZIP + `.sig`, транспорт PDF; СПОЗУ (DWG) — для инвестиционных нелинейных / несоциальных; схемы планов всех этажей (DWG) — при изменении уже выданного свидетельства (в статье — оговорка по городским объектам до 30.08.2026).

Это тот городской этап, под который собран стандартный комплект: НПМ + ВПМ + ЦИМ.

**Итог.** В ЛК — свидетельство или замечания к материалам.

---

## 4. Концепция благоустройства территории

Отдельный вид материалов: согласование проекта благоустройства с НПМ. В стандартный состав моделей ОКС не входит — отдельный объём.

---

## 5. Прочие виды материалов

Выбираются в заявлении по необходимости (в ту же услугу комиссии, но не «комплект АГР ОКС»):

- арт-объекты, инсталляции, монументально-декоративное искусство;
- некапитальные объекты (архитектурно-художественное решение);
- архитектурно-художественные концепции для вывесок;
- крышные информационные / рекламные конструкции;
- реклама на фасаде;
- ветро-пылезащитные и защитные конструкции;
- архитектурно-художественное освещение.

В стандартный состав НПМ/ВПМ/ЦИМ по умолчанию не входят — см. [вопросы-заказчика](../team/вопросы-заказчика.md).

## Как не перепутать этапы в разговоре

| Заказчик говорит | Обычно имеется в виду |
| --- | --- |
| «Нам только концепцию» | Этап 1, одна НПМ, без IFC, без свидетельства |
| «Согласуем НПМ» | Этап 2: НПМ + ЦИМ; для коммерции свидетельство ещё не цель |
| «Идём на АГР / на свидетельство» | Этап 3: НПМ + ВПМ + ЦИМ |
| «Уберите НПМ, оставьте ВПМ» | На этапе ВПМ НПМ всё равно нужна |
