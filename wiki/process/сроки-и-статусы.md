# Сроки и статусы

Разделять **срок изготовления моделей** (наш договор) и **сроки города**. Путать их в разговоре с заказчиком нельзя.

## Сроки города

| Событие | Срок | Комментарий |
| --- | --- | --- |
| Регистрация заявления | ≤ 1 р.д. | С поступления в ИС ДГП |
| Отказ в приёме | до **2 р.д.** (в статье СтроимПросто); в 1423-ПП для отказа — 1 р.д. с поступления в ИС | Это не замечания по геометрии |
| Рассмотрение комиссии | до **20 р.д.** | Облик, транспорт, инсоляция, визуальная интеграция |
| Направление свидетельства после протокола Мэра (без правки ПЗЗ) | **2 р.д.** | Проактивно в ЛК |
| Направление свидетельства после акта по ПЗЗ | **2 р.д.** с утверждения акта | |
| Срок действия свидетельства | **3 года** | С даты оформления |
| Ответ СТП портала (`grad@mos.ru`) | **1 р.д.** | Регламент из FAQ статьи |

Дальше после комиссии срок зависит от очереди совещания с Мэром и (если нужно) правки ПЗЗ. Эту дату мы не назначаем.

## Отказ в приёме {#отказ-в-приёме}

Основания (сжато):

- некорректное / противоречивое заявление;
- неполный комплект;
- формат и содержание не по требованиям;
- файлы не читаются;
- уже есть аналогичное заявление без решения / отказа.

Это **отказ принять пакет**, не список замечаний комиссии. После доработки — новая подача.

## Статусы в личном кабинете

Отслеживание — в разделе заявок ЛК СтроимПросто (в статье встречаются названия «Услуги и заявки» и «Заявки и уведомления»).

| Статус | Что значит |
| --- | --- |
| **Завершено** | Есть скачиваемый итог. Для коммерции на концепции / этапе НПМ это **ещё не** свидетельство АГР |
| **Отклонено** | Есть перечень замечаний; нужна доработка и новое заявление типа «корректировка…» |

Свидетельство статья связывает с итогом этапа ВПМ (и с коротким списком на этапе НПМ) — [этапы-согласования](этапы-согласования.md), [исключения](исключения.md).

## Замечания комиссии

Приходят по итогам рассмотрения (статус «Отклонено»). Повторная подача — новое заявление, тип «Корректировка материалов, по которым ранее получены замечания». См. [замечания-и-корректировка](замечания-и-корректировка.md).

## Наши сроки производства

Типовой ориентир производства: **30 рабочих дней** на НПМ + ВПМ + ЦИМ параллельно с момента ИД — это не 20 дней комиссии. В рабочие дни производства не входят:

- согласование промежуточных материалов заказчиком;
- путь комиссии / Мэра / ПЗЗ.

Сопровождение идёт «в рамках договора» и календарь изготовления не удлиняет.
